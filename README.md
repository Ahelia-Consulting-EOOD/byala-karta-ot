# Национална бяла карта на обществения транспорт в България

Интерактивен dashboard за визуализация на покритието с обществен транспорт за всички **5 256 населени места** в България.

## Основни констатации

- **1 939 (36,9%)** от населените места имат поне една автобусна спирка
- **3 317 (63,1%)** от населените места нямат автобусна спирка
- **1 531 522 души (19,3%)** живеят без достъп до обществен транспорт
- Покритието варира от 97,4% (София) до 7,3% (Сливен)

## Стартиране

```bash
cd dashboard
npm install
npm run dev
```

Отворете http://localhost:5173

## Функционалности

- Карта с всички 5 256 населени места (зелено = с ОТ, червено = без ОТ)
- 10 280 автобусни спирки с клъстеризация
- Пропорционални кръгове по население
- Филтри по област, община, ОТ статус, тип населено място
- Търсене по име на населено място
- Сортируеми таблици по NUTS2 региони и области
- Подчертаване на административни граници при филтриране
- CSV износ на филтрирани данни
- GeoJSON endpoints за интеграция с NAP

## Технологичен стек

- **MapLibre GL JS** -- WebGL рендериране на карта
- **TypeScript** -- типизиран код
- **Vite** -- build инструмент
- **Python** -- pipeline за обработка на данни

## Методология

Предложената методология е базирана на австрийско-швейцарската система OV-Guteklassen (класове на качество на ОТ, A-G), адаптирана за българския контекст. Фаза 1 (текущата) реализира бинарно покритие (има/няма спирка). Следващите фази ще добавят нива на обслужване, свързаност и индекс на транспортна бедност.
