**Версия:** 1.0
**Дата:** 10 април 2026 г.
**Автор:** Михаил-Еренсто Михайлов

## 1. Преглед на фазите

Настоящият план обхваща **единствено Фаза 1** -- бинарен dashboard за покритие с обществен транспорт. Фаза 1 отговаря на въпроса: "Кои от 5 256-те български населени места имат поне една автобусна спирка и кои нямат?"

### 1.1 Обхват на Фаза 1

- Интерактивна карта (MapLibre GL JS v5.22.0) с всички 5 256 населени места, оцветени по ОТ статус
- Слой с 10 280 БДП спирки с клъстеризация
- Странична лента със статистики, филтри, таблици и търсене
- Пропорционални кръгове по население
- GeoJSON endpoints за NAP интеграция
- CSV износ на филтрирани данни
- Статичен хостинг (без backend сървър)

### 1.2 Извън обхвата на Фаза 1

- Маршрутни данни и разписания (Фаза 2)
- OV-Guteklassen класификация A-G (Фаза 2)
- Изохрони и анализ на свързаност (Фаза 3)
- Индекс на транспортна бедност (Фаза 4)
- ЖП транспорт, мобилно приложение, потребителска автентикация

### 1.3 Времева рамка

6 спринта по 3 дни + 1 спринт от 2 дни = **20 работни дни**. Планът е проектиран за бърза доставка от един разработчик с помощта на AI инструменти.

## 4. Стратегия за деплойване

### 4.1 Статичен хостинг: Cloudflare Pages + R2

**Избрана архитектура:**

| Компонент | Хостинг | Причина |
|-----------|---------|---------|
| HTML, JS, CSS, GeoJSON | Cloudflare Pages | Безплатен CDN, автоматичен deploy от GitHub |
| `bulgaria.pmtiles` (~400 MB) | Cloudflare R2 | HTTP Range Requests, без лимит на размер, ~$0.015/GB |

**Алтернативни опции (ранжирани):**

| Опция | За | Против |
|-------|-----|--------|
| GitHub Pages | Напълно безплатно, просто | 100 MB лимит за repo (проблем за PMTiles), 100 GB/месец bandwidth |
| Cloudflare Pages + R2 | Безплатна CDN, R2 за големи файлове, < $1/месец | Минимално по-сложна конфигурация |
| S3 + CloudFront | Неограничен размер, Range Requests | Цена за bandwidth, AWS акаунт |

### 4.2 CI/CD: GitHub Actions

```
push to main
    --> build:data (Python, генериране на GeoJSON)
    --> build:app (Vite, TypeScript -> JS bundle)
    --> test:unit (pytest)
    --> test:e2e (Playwright)
    --> deploy:pages (Cloudflare Pages)
    --> deploy:r2 (ако PMTiles е обновен)
```

**Тригери:**
- Push към `main` -- пълен pipeline
- Push към feature branch -- build + test (без deploy)
- Ръчен тригер -- за обновяване на данни (нов ГРАО файл, нови БДП спирки)

### 4.3 Обновяване на данни

Данните се обновяват ръчно при получаване на нови източници:

1. Заменяне на суровите файлове в `data/raw/`
2. Изпълнение на `npm run build:data`
3. Преглед на `metadata.json` за коректност
4. Commit + push -- CI/CD деплойва автоматично

## 5. Рискове и митигации

| # | Риск | Вероятност | Въздействие | Митигация |
|---|------|-----------|-------------|-----------|
| R1 | PMTiles файлът (~400 MB) не се побира в GitHub Pages | Висока | Блокиращо | Използване на Cloudflare R2 за PMTiles; Pages за останалото |
| R2 | MapLibre GL JS не поддържа WebGL на стари мобилни устройства | Средна | Средно | Graceful degradation: статична карта-изображение + таблица за устройства без WebGL |
| R3 | Данните от БДП за обл. Сливен (7,3% покритие) са аномално непълни | Висока | Ниско | Документиране на ограничението в UI (tooltip/забележка), не е блокиращо за Фаза 1 |
| R4 | GeoJSON payload (~7 MB при всички слоеве) е бавен при 3G връзка | Средна | Средно | Lazy loading на stops.geojson; gzip compression (2-3x намаление); при нужда -- FlatGeobuf |
| R5 | Промяна в API-то на MapLibre GL JS v5.22.0 при minor update | Ниска | Средно | Фиксиране на exact version в package.json; обновяване при нужда |
| R6 | CORS ограничения при достъп до GeoJSON от NAP/ESRI системи | Средна | Средно | Cloudflare `_headers` с `Access-Control-Allow-Origin: *` |
| R7 | Координатите от yurukov/Bulgaria-geocoding са неточни за 4 н.м. | Ниска | Минимално | Документиране; ръчно добавяне на координати в бъдещ спринт |
