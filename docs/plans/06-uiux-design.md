## 1. Принципи на дизайна

### 1.1. Data-first (данните на преден план)

Всеки визуален елемент на интерфейса съществува, за да поддържа четенето и разбирането на данните. Базовата карта е приглушена (dataviz стил), навигацията е минимална, а декоративните елементи липсват. Цветовото кодиране на маркерите (зелено/червено) е единственият доминиращ визуален сигнал.

**Правила:**
- Базовата карта използва почти бяла суша (`#f8f9fa`) и светлосиви пътища, за да отстъпи на данните (FR-09)
- Статистическите карти (cards) в страничната лента показват числата с голям шрифт (24px), а етикетите с малък (12px)
- Таблиците заемат не повече от 50% от височината на страничната лента, за да не изтласкат картата

### 1.2. Достъпност (Accessibility)

Платформата спазва WCAG 2.1 ниво AA (NFR-05, NFR-06). Всички интерактивни елементи са достъпни чрез клавиатура. Цветовете на маркерите са избрани с контрастно съотношение минимум 4.5:1 спрямо белия фон. За потребители с далтонизъм кръговете имат допълнителен визуален индикатор (бял контур с различна ширина).

### 1.3. Минимален хром (Minimal chrome)

Интерфейсът няма заглавна лента (header bar), меню навигация или footer. Единствените хром елементи са:
- Логото и заглавието (вградени в страничната лента)
- Контролите за zoom (вградени в картата, горен десен ъгъл)
- Легендата (долен ляв ъгъл на картата, сгъваема)

Целта е максимална площ за картата и данните.

### 1.4. Прогресивно разкриване (Progressive disclosure)

Информацията се показва на нива:
1. **Национално ниво (fitBounds (национален мащаб)):** Клъстери и обобщени статистики
2. **Областно ниво (zoom 8-10):** Индивидуални маркери, областни граници
3. **Общинско ниво (zoom 11-13):** Надписи на всички н.м., общински граници
4. **Местно ниво (zoom 14+):** Спирки (при включен слой), пълна детайлност

Допълнителни слоеве (спирки, пропорционални кръгове) са изключени по подразбиране и се активират от потребителя (FR-06, FR-07).

## 4. Маркери и символи

### 4.1. Маркери на населени места

**Свързани изисквания:** FR-01, FR-02, FR-05, FR-07

Всяко от 5 256 населени места се показва като кръг с бял контур.

**Визуални свойства:**

| Свойство | Стойност | MapLibre paint |
|----------|----------|----------------|
| Форма | Кръг | `type: 'circle'` |
| Цвят на запълване (с ОТ) | `#16a34a` | `'circle-color': ['case', ['get','has_pt_access'], '#16a34a', '#dc2626']` |
| Цвят на запълване (без ОТ) | `#dc2626` | (виж горе) |
| Непрозрачност | 0.8 | `'circle-opacity': 0.8` |
| Ширина на контура | 1px | `'circle-stroke-width': 1` |
| Цвят на контура | `#ffffff` | `'circle-stroke-color': '#ffffff'` |
| Базов радиус (fitBounds (национален мащаб)) | 4px | `'circle-radius': 4` |
| Радиус при zoom 12 | 6px | Интерполация: `['interpolate',['linear'],['zoom'], 7, 4, 12, 6, 16, 10]` |
| Курсор при hover | pointer | CSS: `canvas { cursor: pointer; }` (при hover на feature) |

**Пропорционални кръгове (Слой 3, FR-07):**

Когато е активен слоят "По население", радиусът на маркера се определя от коренна скала (sqrt) на населението:

```javascript
'circle-radius': [
  'interpolate', ['linear'],
  ['sqrt', ['get', 'population_permanent']],
  0, 3,      // 0 жители -> 3px
  10, 5,     // 100 жители -> 5px
  50, 10,    // 2 500 жители -> 10px
  100, 15,   // 10 000 жители -> 15px
  400, 30    // 160 000+ жители -> 30px
]
```

### 4.3. Стил на клъстерите

**Свързани изисквания:** FR-05

Клъстерите агрегират близки точки при нисък zoom за производителност и четливост.

**Клъстери на населените места:**

| Брой точки | Цвят на фона | Радиус | Текст (число) |
|------------|-------------|--------|----------------|
| 3 - 9 | `#51bbd6` (светло синьо) | 15px | Бял, 12px, удебелен |
| 10 - 49 | `#f1f075` (жълто) | 20px | `#333`, 12px, удебелен |
| 50+ | `#f28cb1` (розово) | 25px | Бял, 13px, удебелен |

**Параметри:**

```javascript
// MapLibre GeoJSON source за населени места
map.addSource('settlements', {
  type: 'geojson',
  data: settlementsGeoJSON,
  cluster: true,
  clusterRadius: 50,
  clusterMaxZoom: 7,
  clusterMinPoints: 3
});
```

**Клъстери на спирките (при включен Слой 4):**

| Параметър | Стойност |
|-----------|----------|
| clusterRadius | 50px |
| clusterMaxZoom | 12 |
| clusterMinPoints | 2 |
| Цвят | `#2563eb` с непрозрачност 0.7 |

**Поведение при клик върху клъстер:** Картата увеличава (zoom) до нивото, на което клъстерът се разпада на индивидуални точки (използва `getClusterExpansionZoom()`).

### 13.4. Z-подредба на слоевете (z-order)

Границите на подчертаване трябва да бъдат ВИНАГИ под маркерите на населените места, за да не ги закриват.

| Z-подредба (отдолу нагоре) | Слой |
|---------------------------|------|
| 1 (най-отдолу) | Базова карта (суша, пътища, водни обекти) |
| 2 | Запълване на подчертана граница (`*-highlight-fill`) |
| 3 | Рамка на подчертана граница (`*-highlight-border`) |
| 4 | Маркери на населените места (кръгове) |
| 5 | Етикети на населените места |
| 6 | Popup |

### 13.5. Преходи (transitions)

При превключване между област и община (или при смяна на избраната единица) подчертаването се сменя плавно.

| Свойство | Стойност |
|----------|----------|
| Продължителност | 0.3s |
| Тип | Fade (промяна на `fill-opacity` и `line-opacity`) |
| CSS / MapLibre | `paint-transition: { duration: 300, delay: 0 }` |
| `prefers-reduced-motion` | При намалено движение преходът е мигновен (0ms) |

### 13.6. Поведение при комбинирани филтри

| Сценарий | Подчертаване |
|----------|--------------|
| Избрана само област | Подчертава се областната граница (solid, 3px) |
| Избрана област + община | Подчертава се само общинската граница (dashed, 2px); областната граница се скрива |
| Нито област, нито община (Всички) | Няма подчертаване; слоевете са скрити |

### 13.7. Достъпност

При появяване на подчертаване екранните четци получават обявление чрез `aria-live="polite"`:

- "Подчертана област: Пловдив"
- "Подчертана община: Карлово, област Пловдив"
- "Подчертаването е премахнато"
