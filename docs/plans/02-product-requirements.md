# Изисквания към продукта (PRD): Национална бяла карта на ОТ

**Версия:** 1.0
**Дата:** 10 април 2026 г.
**Автор:** Михаил-Еренсто Михайлов

---

## 1. Обхват на продукта

### 1.1. Определение

Национална бяла карта на обществения транспорт ("Бялата карта") е уеб-базирана интерактивна платформа за визуализация и анализ на покритието с обществен транспорт в Република България на ниво населено място.

### 1.2. Фаза 1 - обхват (настоящ документ)

Фаза 1 реализира **бинарно покритие** (Ниво 1): за всяко от 5 256 населени места се определя дали има поне една автобусна спирка. Платформата предоставя интерактивна карта с агрегирани статистики по NUTS2 региони, области и общини.

### 1.3. Фази 2-4 - бъдещ обхват (не се реализира в Phase 1)

- Фаза 2: Интеграция на маршрутни данни и класификация A-G (OV-Guteklassen)
- Фаза 3: Анализ на свързаност (изохрони, достъп до услуги)
- Фаза 4: Композитен индекс на транспортна бедност

Архитектурата на Фаза 1 трябва да поддържа разширяване за Фази 2-4 без преработка на съществуващите компоненти.

## 2. Потребителски роли

| Роля | Описание | Основни действия |
|------|----------|-----------------|
| Анализатор (МТС/ИА "АА") | Служител в централна администрация, анализиращ покритието | Преглед по региони, износ на данни, сравнителен анализ |
| Областен планиращ | Служител в областна администрация, планиращ транспортна схема | Филтриране по област/община, идентифициране на бели зони |
| Общински служител | Служител в община, отговорен за местен транспорт | Преглед на населените места в общината, проверка на данни |
| Гражданин | Всеки потребител, търсещ информация за ОТ покритие | Намиране на населено място, преглед на покритие |
| Система (NAP) | Автоматизиран достъп от Национална точка за достъп | Консумиране на GeoJSON endpoints |

## 6. Модел на данните (обобщение)

### 6.1. Основна същност: Населено място

```
Settlement {
  ekatte: string(5)           // PK, ЕКАТТЕ код
  name: string                // Име на кирилица
  name_en: string             // Име на латиница
  type: enum("с.","гр.","ман.")
  oblast: string              // Област
  obshtina: string            // Община
  nuts2: string               // NUTS2 регион
  nuts3: string               // NUTS3 регион
  population_permanent: int   // Постоянно население
  population_current: int     // Настоящо население
  lon: float                  // WGS84
  lat: float                  // WGS84
  has_pt_access: boolean      // Има ли поне 1 спирка
  bdp_stop_count: int         // Брой БДП спирки
  // Phase 2+ (nullable)
  ov_gk_class: string?        // Клас A-G
  route_count: int?           // Брой маршрути
  service_frequency: float?   // Дневна честота
  transport_poverty_index: float?  // Индекс 0-1
}
```

### 6.2. Поддържаща същност: Автобусна спирка

```
BusStop {
  id: int                     // PK от БДП
  lon: float                  // WGS84
  lat: float                  // WGS84
  oblast: string
  municipal: string
  city: string
  road: string
  road_type: enum("улица","път")
  settlement_ekatte: string   // FK -> Settlement
}
```

### 6.3. Агрегирани изгледи

- Покритие по NUTS2: 6 региона с общо н.м., н.м. с ОТ, население с/без ОТ
- Покритие по област: 28 области със същите метрики
- Покритие по община: 266 общини (при филтриране)

## 7. Ограничения и допускания

### 7.1. Допускания

1. **БДП = авторитетен източник за спирки.** Приемаме, че БДП съдържа найпълната и найактуална информация за автобусни спирки, тъй като е резултат от целенасочена инвентаризация чрез Общински комисии по БДП
2. **Спирка = ОТ.** Наличието на поне 1 спирка в населено място се приема за наличие на обществен транспорт. Това е опростяване - някои спирки могат да са административно определени, но без реално обслужване
3. **Центроид = представителна точка.** Координатите на населеното място (от yurukov/Bulgaria-geocoding, базирани на OSM) представляват неговия център
4. **Данните за население от ГРАО са актуални.** Използваме данни по постоянен адрес от 15.03.2026 г.

### 7.2. Известни ограничения

1. **Област Сливен:** Покритието от 7,3% е аномално ниско и може да отразява непълно участие на общините в инвентаризацията на БДП, а не реално отсъствие на ОТ
2. **Обезлюдени села:** 194 населени места с 0 население са включени в общия брой (5 256), но не влияят на демографските статистики
3. **Липсващи координати:** 4 от 5 256 населени места нямат координати; те се показват в таблиците, но не на картата
4. **Бинарна оценка:** Фаза 1 не отчита качеството на обслужване - населено място с 1 курс седмично получава същия статус като населено място с 50 курса дневно
